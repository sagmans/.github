# Security Policy

This policy applies to every repository in the [sagmans](https://github.com/sagmans) organization that does not have its own `SECURITY.md`.

## Reporting a vulnerability

Please **do not** open a public issue, discussion, or pull request for a security problem.

Report it privately with GitHub's private vulnerability reporting:

1. Open the affected repository on GitHub.
2. Go to the **Security** tab.
3. Click **Report a vulnerability** and fill in the form.

Include, if you can:

- the affected repository, version, or commit
- steps to reproduce, or a proof of concept
- the impact you expect

## What to expect

- We acknowledge reports as soon as we can, usually within a few days.
- We keep you informed while we investigate and fix the issue.
- We credit reporters in the published advisory unless you ask us not to.

## Supported versions

Only the latest release of each project receives security fixes, unless that project's own documentation says otherwise.
